# 🔁 Desafios de Lógica — Estruturas de Repetição (Loops)

> Exercícios para praticar **laços de repetição (for, while, do...while)** em qualquer linguagem de programação.  
> Use `print`, `console.log`, `printf`, `System.out.println`, etc., para exibir os resultados.

---

## 📘 Instruções Gerais

- Resolva os desafios na linguagem que preferir.  
- Pode usar `for`, `while` ou `do...while` (ou o equivalente na sua linguagem).  
- Teste seu código no **VS Code**, **Dev C++**, **terminal**, ou outro ambiente.  
- Exiba o resultado de cada exercício.

---
