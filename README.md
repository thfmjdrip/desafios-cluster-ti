## 🎯 Sobre os Desafios

Todos os exercícios foram criados para que possam ser resolvidos em **qualquer linguagem de programação**.  
A minha especialidade é **JavaScript**, então me perdoe se encontrar algum errinho ou exemplo mais voltado pra essa linguagem 😅  

O foco é **praticar lógica**, não decorar sintaxe.  

---

## 🧩 Como Participar

1. Escolha um dos tópicos ou listas de exercícios disponíveis.  
2. Resolva os desafios no seu próprio ritmo, na linguagem que preferir.  
3. Mostre seu resultado lá no Discord!  

> 💬 **Você não precisa fazer um pull request** aqui no repositório, basta mandar um **print do seu terminal** na aba do Discord onde estarei postando os links dos desafios.  
>
> Mas se quiser, também pode fazer um **pull request** para que eu possa fazer o *merge* depois.

---

## 🪄 Dicas

- Comente o seu código — entender *o porquê* do que você faz é o mais importante!  
- Não tenha medo de errar. Cada erro te ensina algo.  
- Use o console, o terminal ou um compilador online pra testar suas ideias.  
- Divirta-se enquanto aprende! 🚀
